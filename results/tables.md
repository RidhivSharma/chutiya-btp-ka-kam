# Phase 6 tables

All values below are generated by `src/make_figures.py` from the saved CSV and JSON files named under each table. No model was retrained, no score or threshold was changed, and no fault file was used to make a modeling decision. The two proposed variants are reported side by side in every table where they appear, and the healthy-test false-alarm rate is shown next to every performance table. `Proposed (featnorm)` is a negative result: its healthy-test false-alarm rate is high in both modes, so fault-detection values must be read together with that rate. This report does not claim that either proposed variant exceeds any baseline.
